# 📊 Data Professionals Survey Analysis – Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing survey responses from data professionals across different countries using Microsoft Power BI. The dashboard provides insights into salaries, job roles, programming language preferences, career transitions, and job satisfaction.

The objective is to transform raw survey data into meaningful visual insights that help understand trends in the data industry and the experiences of professionals working in different data-related roles.

## 🎯 Project Objectives

- Analyze salary trends across different data-related job roles.
- Identify the most popular programming languages among data professionals.
- Understand the geographical distribution of survey respondents.
- Examine job satisfaction levels, including salary and work-life balance.
- Explore career transition trends and challenges faced by professionals entering the data industry.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Calculated measures and KPIs.
- **Microsoft Excel** – Source dataset.

## 📂 Project Workflow

1. **Data Import:** Imported the survey dataset into Power BI from Excel.
2. **Data Cleaning:** Removed unnecessary columns, handled inconsistent values, and standardized data.
3. **Data Transformation:** Split salary ranges, created average salary columns, and grouped similar job titles and programming languages.
4. **Data Modeling:** Prepared the transformed data for analysis.
5. **DAX Calculations:** Created measures to calculate key performance indicators and average metrics.
6. **Data Visualization:** Developed interactive charts, cards, and other visuals to represent survey findings.
7. **Dashboard Development:** Combined visualizations into an interactive report for exploring data professional trends.

## 📈 Dashboard Analysis

The dashboard explores the following areas:

### 1. Survey Overview
- Total number of survey respondents.
- Average age of respondents.
- Average salary of data professionals.
- Average happiness with salary.
- Average happiness with work-life balance.

### 2. Salary Analysis
- Comparison of average salaries across different job titles.
- Salary distribution across countries.
- Comparison of average salaries by gender.
- Identification of higher-paying data-related roles.

### 3. Programming Language Preferences
- Most popular programming languages among data professionals.
- Comparison of language preferences.
- Identification of the most commonly preferred language.

### 4. Career & Job Satisfaction Analysis
- Percentage of professionals who switched careers into data.
- Difficulty faced when entering the data industry.
- Satisfaction with salary and work-life balance.
- Comparison of job satisfaction across countries.

## 🔍 Key Insights

The analysis helps uncover the following trends:

- **Programming Language Preference:** Python emerges as the most popular programming language among data professionals.
- **Salary Trends:** Data Scientists generally report higher average salaries compared with several other data-related job roles.
- **Career Transition:** The survey highlights the challenges faced by individuals transitioning into the data industry.
- **Salary Satisfaction:** Salary satisfaction varies across countries and professional roles.
- **Work-Life Balance:** Work-life balance satisfaction differs across geographical regions.
- **Gender-Based Analysis:** Comparing salaries across genders helps identify differences in compensation across countries.
- **Global Distribution:** The survey provides an overview of data professionals working across different countries.
